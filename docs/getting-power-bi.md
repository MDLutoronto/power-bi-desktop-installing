## Getting Power BI Downloaded & Installed

1. Once you have the Power BI Service Homepage open, navigate to the top right of the screen, where you'll find the download button available. This will open a drop\-down menu \- select the Power BI Desktop option. This will open the Microsoft Store.

    <img src='/assets/images/%7BDDE62369-9CAD-44E9-B50E-147CE5AA3C8F%7D.png' alt='Downloading Power BI Desktop' title='' width='649' height='233' />
2. If you are prompted to *Open Microsoft Store*, allow it and the Microsoft Store application will open.
3. In the Microsoft Store, click on *Get* and the application will begin downloading to your device.

    <img src='/assets/images/%7B3A08F2A3-6085-4659-83B7-B532DB504293%7D.png' alt='Power BI in the Microsoft Store' title='' width='650' height='260' />
